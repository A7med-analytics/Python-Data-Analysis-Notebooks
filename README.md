# Python Data Analysis & Engineering Notebooks

A practical collection of Jupyter Notebooks focusing on real-world data analysis, API data ingestion, data wrangling, and database storage using Python.

---

## 📂 Notebooks & Projects

| Notebook | Tools | Summary |
| :--- | :--- | :--- |
| **[`Developer Survey EDA & Data Wrangling.ipynb`](./Developer%20Survey%20EDA%20%26%20Data%20Wrangling.ipynb)** | `pandas`, `numpy` | Exploratory data analysis on 65k+ survey responses, handling missing values, and mapping demographic age ranges. |
| **[`Job Market API Data Ingestion & SQL ETL.ipynb`](./Job%20Market%20API%20Data%20Ingestion%20%26%20SQL%20ETL.ipynb)** | `requests`, `sqlite3`, `json` | Fetching job postings via REST API, filtering skills demand, and persisting records into a local SQLite database (`jobs.db`). |
| **[`Python HTTP & API Requests Essentials.ipynb`](./Python%20HTTP%20%26%20API%20Requests%20Essentials.ipynb)** | `requests` | Working with HTTP GET requests, passing query parameters, handling headers, and parsing JSON responses. |

## 🛠️ Stack & Libraries
* **Language:** Python

* **APIs & Web:** Requests
